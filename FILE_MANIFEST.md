## 🔌 API Endpoint Mapping

### Complaint Endpoints
```
GET    /api/complaints              → getComplaintById()
POST   /api/complaints              → submitComplaint()
GET    /api/complaints/{id}         → getComplaintById()
GET    /api/complaints/{id}/track   → trackComplaint()
GET    /api/complaints/nearby       → getNearbyComplaints()
GET    /api/complaints/statistics   → getStatistics()
PATCH  /api/complaints/{id}/status  → updateComplaintStatus()
```

### User Endpoints
```
GET    /api/users/me                → getUserProfile()
GET    /api/users/{id}/impact       → getCommunityImpact()
```

### Notification Endpoints
```
GET    /api/notifications           → getNotifications()
PATCH  /api/notifications/{id}/read → markNotificationRead()
```

### Health Endpoint
```
GET    /health                      → HealthCheck
```
